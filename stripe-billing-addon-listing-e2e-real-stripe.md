## Test Scenario

**Gap identified:** All existing Playwright specs for addon purchase (`addon-add.spec.ts`) explicitly **avoid clicking the "Añadir" button** to prevent real Stripe subscription item mutations. No MCP E2E test had ever performed a real addon purchase via the UI button click — confirming the full lifecycle: dialog confirmation → POST to Stripe → invoice creation → UI update → cleanup.

**Scenario executed:**  
1. Login as test3@zonacnc.com  
2. Navigate to `/module/zonacncplans/subscription`  
3. Verify "Añadir add-on a tu plan" section  
4. Click "Añadir" for "Anuncio extra" (listing addon, qty=1 × 3.00€/mes)  
5. Accept native `confirm()` dialog  
6. Verify new addon appears as "Activo" in addons table  
7. Verify prorated invoice appears in billing history with PDF + Stripe link  
8. Cancel addon (cleanup)

### ❌ BUG FINDING: Featured addon (`data-zcnc-addon-type="featured"`) not available

**Observation:** The `addon-add.spec.ts` test expects a `[data-zcnc-addon-type="featured"]` button to exist alongside the listing type. However, the subscription page for test3 (Enterprise plan) **only shows** "Anuncio extra" (listing). No "Destacado" (featured) addon card is rendered.

**Investigation:**  
- Full page HTML search for "destacado" or "featured": **0 matches**  
- `[data-zcnc-addon-type]` elements: only `type="listing"` found  
- Grid class contains empty `<div>` after listing card — no hidden elements  
- No hidden/display-none elements with addon-related content

**Impact:** The "Destacado" addon cannot be purchased by this user/plan. It's unclear if this is:
- A UI bug (featured addon should be available but isn't rendered)  
- A plan restriction (featured only available on certain tiers)  
- A stock/inventory issue (sold out)

The addon-add.spec.ts test still PASSES because it uses `toBeGreaterThanOrEqual(1)` (checks for at least 1 addon button total), masking the missing featured addon.
