### Recommendation
1. **Increase submit button height** from 38px to ≥44px at all breakpoints — cheap CSS fix (`button[type="submit"] { min-height: 44px }`)
2. **Increase checkbox/radio hit areas** using invisible expanded touch targets (pseudo-element padding or min-size)
3. **Consider sticky CTA** on mobile: long registration form means user scrolls 800+px to submit
