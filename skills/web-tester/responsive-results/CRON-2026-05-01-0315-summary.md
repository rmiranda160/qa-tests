## ⚠️ Issues Found

### 1. 🔴 BUG: 404 Page Search Form Broken (No-JS Fallback)

- **Page:** 404 Error
- **Severity:** HIGH
- **Reproducibility:** Always
- **Detail:** The 404 page renders a `<form class="recovery-search" method="get" action="/busqueda">`. On the live site, `GET /busqueda?q=torno` redirects to the homepage (`/es/`) instead of searching. The JS rewrite converts `/busqueda` to `/buscar` at runtime, but **without JavaScript** (crawlers, slow connections, accessibility tools) the search silently redirects to the homepage.
- **Evidence:** 
  - `GET /busqueda?q=torno` → `302 → /es/`
  - `GET /buscar?q=torno` → 200 with results
- **Recommendation:** Set the 404 form action directly to `/buscar` instead of `/busqueda`.

### 2. 🟡 Manufacturers Page Size (510KB HTML)

- **Page:** Manufacturers
- **Severity:** MEDIUM
- **Detail:** 2461 brand items rendered as raw HTML with no pagination. 924 links, 147 collapse elements, 510KB body size. Mobile users on slow connections will experience significant load latency.
- **Evidence:** `BODY_SZ: mobile=510010 desktop=510010`
- **Recommendation:** Implement pagination (e.g., 50 per page) or lazy-loaded alphabetical sections for brand listing.

### 3. 🟡 No Search Filter for 2461 Brands

- **Page:** Manufacturers
- **Severity:** MEDIUM
- **Detail:** 0 search filter elements, 0 pagination controls. Users must scroll through 2461 brand logos alphabetically with no search/autocomplete.
- **Recommendation:** Add a brand search/autocomplete input at the top.

### 4. 🟡 404 Page: No Canonical URL

- **Page:** 404 Error
- **Severity:** LOW
- **Detail:** The 404 page has no `<link rel="canonical">` tag, while both Search and Manufacturers pages have canonical URLs set correctly.
- **Recommendation:** Add `<link rel="canonical" href="https://new.zonacnc.com/es/page-not-found">` or set to the current 404 URL.

### 5. 🟡 404 Page: Google One Tap OAuth

- **Page:** 404 Error
- **Severity:** LOW
- **Detail:** The Google One Tap sign-in script (`accounts.google.com/gsi/client`) and data attributes are present on the 404 page. This is unnecessary for an error page and triggers an extra 3rd-party load.
- **Recommendation:** Conditionally exclude Google OAuth from the 404 page layout.

### 6. 🟢 Search Results: Client-Side Only Listing

- **Page:** Search Results
- **Severity:** INFO
- **Detail:** Product listing data (285 anuncios) is rendered via JS/AJAX only — no product cards in initial HTML. The initial HTML only shows the filter sidebar and product count.
- **Recommendation:** Consider server-side rendering for the first page of results to improve SEO and no-JS accessibility.
