## ⚠️ BUGS & WARNINGS

### 🔴 BREA-1 (NEW): Breadcrumb horizontral overflow on mobile
| | |
|---|---|
| **Severity** | **MEDIUM** |
| **Breakpoint** | Mobile (375×812) |
| **Description** | The breadcrumb last item (`<li>`) has `white-space: nowrap` causing the long page title "Cómo funciona ZonaCNC — Marketplace B2B de maquinaria industrial" to overflow horizontally. scrollW=491 vs clientW=375 (116px extra). No text truncation or wrapping applied. |
| **Root cause** | Breadcrumb `<li>` elements inherit/applied `white-space: nowrap`. Text is too long for 375px viewport (breadcrumb container is 351px wide). No `overflow: hidden` or `text-overflow: ellipsis`. |
| **Impact** | Minor — user can still scroll horizontally but layout is broken. On pages with even longer titles (e.g. nested categories), this could be worse. |
| **Fix suggestion** | Add `white-space: normal` to `.breadcrumb-item` at mobile breakpoints, or add `overflow: hidden; text-overflow: ellipsis; max-width: 100%`. |
