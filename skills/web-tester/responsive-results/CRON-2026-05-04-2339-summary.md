## Findings

### 🔴 ISSUE-1: Tablet — Missing text labels on nav icons
- **Viewport:** 768×1024
- **Location:** Top navigation bar
- **Description:** Text labels for "Vendedores", "Tarifas", "Categorías", "Vender máquina" disappear at tablet breakpoint, leaving only icons. Users may not understand icon-only links.
- **Severity:** Medium (UX regression)
- **Expected:** Icons should retain text labels or have accessible `aria-label`/`title` attributes.

### 🔴 ISSUE-2: Mobile — Top nav links hidden without hamburger menu
- **Viewport:** 390×844
- **Location:** Header top bar
- **Description:** Links "Contacte con nosotros", "Vendedores", "Tarifas" are completely hidden at mobile breakpoint with no hamburger/alternative menu to access them.
- **Severity:** High (key navigation links inaccessible)
- **Expected:** A hamburger menu or bottom nav should provide access to these links.

### 🟡 ISSUE-3: Cookie consent overlay on every page
- **Viewport:** All
- **Description:** The cookie consent dialog appears on every page load. Users must accept it to access content. This is expected for first visit but reappears in test environment.
- **Severity:** Low (expected behavior, may be test env artifact)

### 🟢 ISSUE-4: Google Sign-In console errors
- **Viewport:** All
- **Description:** 2–3 console errors related to Google Sign-In (likely `gapi` / OAuth init failing in test environment). Not a production concern but logged.
- **Severity:** Low (test environment only)
