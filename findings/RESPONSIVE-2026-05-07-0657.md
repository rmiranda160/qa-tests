## ⚠️ Minor Observations (Non-blocking)

### 1. Footer accordion toggle buttons — undersized touch targets
- **Element:** "Mostrar/ocultar enlaces de…" buttons in footer
- **Size:** 24×26px
- **WCAG 2.1 Target:** 44×44px (2.5.5)
- **Impact:** Difficult to tap accurately on mobile
- **Severity:** Low — footer links are also accessible via direct `<a>` tags

### 2. Skip-to-content link — invisible
- **Element:** "Ir al contenido principal" link
- **Size:** 1×1px (visually hidden but not focusable-visible)
- **Impact:** Keyboard users cannot see the skip link on focus
- **Severity:** Low

### 3. Console errors (non-responsive, pre-existing)
- Google Sign-In FedCM: `Error retrieving a token`
- `Unexpected token '&'` — JS parsing error
- `Not signed in with the identity provider`
- These are auth/GAPI issues, not responsive defects
